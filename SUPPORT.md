# Getting help

- **Questions and bugs:** open a GitHub issue with the
  [question, bug report or feature request template](https://github.com/tenishai/gojira/issues/new/choose).
  For a bug, include the `gojira.yaml`, the ledger rows on the app page and the
  pod's log for the step that failed.
- **Security problems:** don't open a public issue. Report them privately as
  [SECURITY.md](SECURITY.md) describes.

This project doesn't use GitHub Discussions, so issues are the place for questions too.
